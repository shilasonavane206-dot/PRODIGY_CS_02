# PRODIGY_CS_02 – Image Encryption

## Project Overview
This project demonstrates image encryption and decryption using pixel manipulation with Python and the Pillow library.

It uses the XOR operation to encrypt and decrypt image pixel values.

## Features
- Encrypt an image using XOR pixel manipulation.
- Decrypt the encrypted image using the same secret key.
- Convert an image into Black & White.
- Apply a strong Gaussian Blur effect.
- Save the processed images as separate files.

## Technologies Used
- Python
- Pillow (PIL)
- Pixel Manipulation
- XOR Operation

## Installation

Install the required library:

```bash
python -m pip install pillow
```

## How to Run

1. Clone or download this repository.
2. Keep your input image named `input.png` in the project folder.
3. Run the Python program:

```bash
python image_encryption.py
```

## Output Files
- `encrypted.png` – Encrypted image.
- `decrypted.png` – Decrypted image.
- `black_white_blur.png` – Black & White blurred image.

## Learning Outcomes
- Understanding RGB pixel values.
- Learning XOR-based encryption and decryption.
- Working with Python Pillow.
- Applying image processing techniques.

## Note
This is an educational demonstration of XOR-based image encryption. It is not intended for production-level secure encryption.
